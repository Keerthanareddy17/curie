# Attribution

curie is a derivative work that builds on [Billie Gene](https://github.com/WeiningLi/billiegene)
by Weining Li, an MIT-licensed research prototype for computational vaccine-design exploration
(sequence intake -> surface protein screening -> structure modeling -> epitope scoring ->
conceptual mRNA construct -> research dossier).

Two separate MIT licenses apply in this repository, and they are not the same file:

- The repository root `LICENSE` covers curie's own original contributions.
- [`frontend/legacy/LICENSE-BILLIEGENE`](../frontend/legacy/LICENSE-BILLIEGENE) is Billie
  Gene's actual original license text (copyright Weining Li), preserved verbatim alongside the
  vendored Billie Gene assets it covers. It was not merged into or replaced by the root license.

Nothing in this repository revokes or supersedes Billie Gene's license; it continues to apply
to the vendored assets in `frontend/legacy/` and to the logic ported from `src/utils.ts`
described below.

## What was inspected

The upstream repository was cloned and read in full (`server.ts`, `src/App.tsx`, `src/sandbox.ts`,
`src/utils.ts`, `src/data.ts`, `src/types.ts`, `src/components/Molecular3DVisualizer.tsx`,
`src/components/MarkdownRenderer.tsx`) and the original app was run locally to confirm what it
actually does versus what it narrates.

## What was carried forward

| Asset | Origin | Disposition in curie |
|---|---|---|
| `Molecular3DVisualizer.tsx` | `billie-gene/src/components/` | Vendored verbatim into `frontend/legacy/` — a genuine, working 3Dmol.js viewer with a real call to the public ESM Atlas ESMFold API (`api.esmatlas.com`) and a synthetic-helix fallback when that API or WebGL is unavailable. This is real, reusable visualization code and is kept for future frontend work. |
| `esmfold-demo.pdb` | `billie-gene/` and `billie-gene/public/` | Vendored into `frontend/legacy/` as a demo structure asset. |
| Kyte-Doolittle hydrophobicity scale, Kolaskar-Tongaonkar antigenicity scale, `cleanSequence`, `calculateResidueComposition` | `billie-gene/src/utils.ts` | Reimplemented in Python at `curie/shared/sequence_utils.py`, unit-tested. These are standard, citable biochemical reference tables/formulas, not invented by Billie Gene, but the encoding of them was a legitimate, reusable piece of the original codebase. |
| `PATHOGEN_PRESETS` (SARS-CoV-2 Spike, H5N1 HA1, Ebola GP, Zika E, with real accession IDs) | `billie-gene/src/data.ts` | Reimplemented as `tests/fixtures/sample_sequences.py` for use as realistic example inputs and test fixtures. |
| ESM Atlas ESMFold REST call pattern (`POST https://api.esmatlas.com/foldSequence/v1/pdb/`) | `billie-gene/src/App.tsx`, `Molecular3DVisualizer.tsx` | Confirmed live and working (no API key required) and reimplemented as a real Python tool client at `curie/tools/esm_atlas.py`. |

## What was deliberately not carried forward

Everything else in Billie Gene's pipeline — the "Master Coordinator" plan, the six named subagents,
the master dossier, and every population-genetics / PharmGKB / ClinVar / CPIC / 1000 Genomes claim —
is either:

1. A hardcoded fallback string returned when no `GEMINI_API_KEY` is set (`server.ts`, `sandbox.ts`), or
2. Free-text generated by a Gemini prompt that *names* those databases without ever calling them
   (`server.ts`'s `/api/orchestrate` and `/api/run-step` routes).

No real UniProt, IEDB, Europe PMC, PharmGKB, ClinVar, CPIC, or 1000 Genomes API call exists
anywhere in the original codebase — confirmed by full-text search of the repository. Likewise,
no DNA/RNA-to-protein translation or codon-table logic exists in the original codebase, despite
"ORF translation" being listed as a skill in the UI copy: it is narrated, not implemented.

curie's premise is precisely that this gap — plausible-sounding, ungrounded scientific narration —
is the failure mode to design against. curie's tools call real public bioinformatics APIs
(ESM Atlas, UniProt, IEDB, Europe PMC) and its evidence-verification and evaluation layers exist
to make the trustworthiness of a conclusion explicit and checkable, rather than assumed.

## Research-use limitation

curie is research and education software. It does not produce clinically validated results,
does not constitute a therapeutic recommendation, and is not wet-lab ready. See
[`LIMITATIONS.md`](./LIMITATIONS.md).
